# Security reporting

This is a LocalGCloud fork of Google's Cloud Spanner emulator. Google's
vulnerability intake and response-time commitments apply to Google's upstream
project, not to this fork.

No private contact for vulnerabilities specific to this fork is documented in
this repository. If you already have a private channel to the LocalCloud
maintainers, use it for a fork-specific report. Do not post vulnerability
details in a public issue.
